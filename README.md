# 💰 Финансовый Планер

**Описание:**  
Это простое **Python приложение** с графическим интерфейсом для учета ваших расходов и доходов, анализа финансов и визуализации данных.

---

## 🌟 Особенности:
- **Добавление операций:** доходов и расходов
- **Удаление выбранных записей**
- **Фильтрация данных по дате**
- **Аналитика:** диаграммы расходов и доходов
- **Статистика по месяцам**
- **Интуитивный графический интерфейс** на базе `tkinter`
---


## ⚙️ Структура проекта:

- `storage.py` — работа с CSV файлами
- `models.py` — модель операции
- `analysis.py` — функции анализа и визуализации
- `gui.py` — графический интерфейс
- `startScreen.py` — стартовый экран с анимацией
- `main.py` — главный запускной скрипт
